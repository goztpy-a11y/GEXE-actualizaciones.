# GEXE — Actualizaciones para Windows

Repositorio oficial de distribución de GEXE para Windows de 64 bits.

[Descargar instalador GEXE](https://github.com/goztpy-a11y/GEXE-actualizaciones./releases/latest/download/GEXE-Setup.exe)

[Descargar paquete ZIP](https://github.com/goztpy-a11y/GEXE-actualizaciones./releases/latest/download/GEXE-Setup.zip)

Cerrá GEXE antes de ejecutar el instalador. Los libros y la conexión Google locales se conservan. El instalador incluye los componentes necesarios; no requiere instalar .NET por separado. Todavía no tiene firma digital comercial.

La app consulta `gexe-update.json` de la última versión publicada y ofrece la descarga cuando es más nueva que la instalada. Los borradores no se anuncian y la instalación requiere ejecutar el instalador.

La prueba gratis dura cinco días desde el primer inicio de la versión que implementa la prueba en ese perfil de Windows. Al vencer, se requiere licencia para editar o sincronizar; los libros se conservan y se permite guardar una copia y descargar actualizaciones.

La versión y el estado de cobros se detallan en [Releases](https://github.com/goztpy-a11y/GEXE-actualizaciones./releases). Al preparar GEXE 1.1.4, ambas páginas de pago siguen en modo de prueba; no se deben anunciar cobros reales habilitados.

Este repositorio no contiene libros de usuarios, contraseñas ni tokens de sesión de sus cuentas.
