# GEXE — Actualizaciones para Windows

Repositorio oficial de distribución de GEXE.

Los instaladores se publican en [Releases](https://github.com/goztpy-a11y/GEXE-actualizaciones./releases).

Cada versión incluye `GEXE-Setup.zip` y `gexe-update.json`. GEXE consulta la última versión estable publicada y ofrece su descarga cuando es más nueva que la instalada. Los borradores no se anuncian.

La primera publicación de la aplicación está pendiente. Este repositorio no contiene libros de usuarios ni credenciales de sesión.
